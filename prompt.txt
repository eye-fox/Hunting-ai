# 2. FASE HUNTING KELAS VULN (prioritas dari intel sebelumnya)

# 2A. shop-chat-agent (P1 — prioritas #1)
Subagent bug-hunter-sub + general, mode "2-account differential":
- SSRF: endpoint /chat — kirim `Origin: https://<kolaborator-mu>` ;
  amati fetch server-side (server log / collaborator) ke
  /.well-known/customer-account-api dan /api/mcp. Cek apakah
  hostname dari Origin bisa diarahkan ke localhost/metadata
  (169.254.169.254, localhost:PORT, internal domain) —
  coba juga rotate: Origin kosong, Origin dengan port, Origin
  attacker.domain dengan DNS rebinding.
- CORS: verifikasi refleksi Origin + Access-Control-Allow-Credentials;
  buktikan preflight OPTIONS diizinkan origin attacker.
- IDOR conversation_id: akun A login (token valid), akun B panggil
  /chat?history=true&conversation_id=<id-A> tanpa auth → bisa baca
  riwayat & token?  Cek db.server.js penyimpanan token per
  conversationId; uji prediksi id (Date.now) & enumerasi.
- PKCE downgrade: callback tanpa code_verifier — apakah token exchange
  tetap sukses? Jika ya → login CSRF/account takeover.
- Prompt injection → tool: kirim pesan yang menyuruh agent memanggil
  tool berbahaya (purchase, payment, refund); uji loop tak terbatas
  (cost abuse). Dokumentasikan tool apa saja yang diekspos MCP.
- Error leak: pastikan error.message mentah (stack, token fragment)
  bocor ke respons.
- Validasi akhir: PoC penuh (request+response) untuk setiap temuan.

# 2B. subscriptions-reference-app (P1)
Subagent bug-hunter-sub:
- /internal/jobs/run: uji di instance lokal/staging — kirim POST
  {jobName, parameters} tanpa header auth → respon? Cek apakah
  ada middleware/entrance yang tidak ada di kode publik (uji
  langsung di deployment yang kamu kontrol).
- Charge bypass: RebillSubscriptionJob dengan originTime retroaktif →
  apakah state transition diakui Shopify API (pakai sandbox shop).
- Mass assignment: SubscriptionContractDraft server (updateAddress/
  updateLine) — coba field tidak terduga via GraphQL.
- Webhook HMAC: verifikasi handler webhook menolak payload tanpa
  signature valid (uji HMAC kosong/salah).

# 2C. hydrogen (P1)
Subagent bug-hunter-sub + general:
- Cookie session skeleton: grep SEMUA `createCookieSessionStorage`
  / cookie options — catat flag secure/httpOnly/sameSite di tiap
  cookie (session, cart, localization, multipass). Uji cookie
  dikirim via HTTP saat deployment HTTP (jika ada instance sendiri).
- Multipass token: periksa validasi `created_at`/expiry di
  multipassify.server.ts — mint token lalu pakai setelah melewati
  TTL; apakah tetap diterima?
- return_to/redirect: fuzz parameter redirect di routes auth &
  checkout — pastikan hanya local path (uji 20+ varian payload:
  //evil.com, /\evil.com, https://evil.com@local, %2F%2F, dsb).
- SSR/cache: cari header cache pada halaman authenticated; cek
  apakah respons user-specific ter-cache publik (CDN poisoning).

# 2D. shopify_app (Rails engine) — auth-focused
Subagent bug-hunter-sub (target: aplikasi DEMO/self-hosted milikmu
yang memakai gem ini):
- Open redirect pasca-OAuth: /login?return_to=https://evil.com →
  selesaikan OAuth dengan sandbox shop → amati redirect final.
  Varian: return_to encoded, multi slash, protocol-relative,
  backslash, @ trick, param pollution (return_to ganda).
- CSRF bypass via id_token: tanpa token CSRF, POST ke endpoint
  sensitif dgn `?id_token=<valid>` — apakah diterima?
- Session fixation: cek apakah session id dirotasi setelah login
  (bandingkan cookie sebelum/sesudah callback).
- App proxy signature: uji parameter array (k[]) canonicalization.

# 2E. shopify_python_api
Subagent:
- Login CSRF: exchange token tanpa state — apakah diterima? Uji
  di aplikasi Python demo yang kamu deploy sendiri.
- JWT tanpa exp: buat session token tanpa klaim exp — diterima?
- timestamp future: uji replay dengan timestamp mendatang.

# 2F. checkout-sheet-kit (RN + Swift)
Subagent:
- Deeplink: uji universal link ke URL mengandung /checkout &
  /cart dengan domain non-storefront — apakah sheet terbuka?
- open_externally=true → apakah scheme arbitrary (tel:, app://)
  diteruskan ke OS?
- WebView cross-origin: halaman checkout yang redirect ke domain
  lain — apakah navigasi tetap diizinkan (cookies ikut)?

# 2G. omniauth-shopify-oauth2 + ghostferry + template
Subagent ringan: cek state validation path & provider_ignores_state;
ghostferry: HTTP control server auth (lookup & bypass).

teori)? 3. In-scope program? 4. Bukan N/A (mis. by-design/low)?

batas izin?

  race/single-packet, chaining (chain-builder). Setelah semua varian
  mati baru DROP.
